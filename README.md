# Block site

The website of the Block iPhone app, served by GitHub Pages at https://block.lnkd.world: the landing pages, the AI guides, the privacy policy, support, and the sign-in page that AI assistants open. The fonts are Archivo (SIL Open Font License, see fonts/OFL.txt).

The pages come from the app's private repo (tools/site/publish.sh). Change them there, not here.
